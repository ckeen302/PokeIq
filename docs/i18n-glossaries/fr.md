# PokéIQ fr-FR glossary (French review)

Register: tu (tu/ton/toi); vous only for "you all" in group modes (partagez, défiez-vous).
Typography: a narrow no-break space (U+202F) before ! ? ; and a no-break space (U+00A0) before : (« Super efficace ! »,
« Erreurs : 3 »). Quotes: « … » with no-break spaces inside. Apostrophe: ’ in new text (l’histoire); the code never
depends on which one is used. Ellipsis: … (one character).
Numbers: formatted by code (1 234, 3,5 m); percent "{n} %". Puzzle numbers keep "#" ("Quotidien #{n}", "Hebdo #{n}",
as French players write them); other numbering is "n° {n}"; Pokédex numbers "#{num}" as in the games' UI; ranks "{n}e".
