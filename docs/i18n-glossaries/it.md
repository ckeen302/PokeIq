# PokéIQ it-IT glossary (Italian review)

Register: tu (tu/tuo/ti); voi only for "you all" in group modes (condividete, sfidatevi).
Typography: no space before ! ? : ; (unlike French). Quotes: « … » or “…”; apostrophe ’ in new text (l’avversario).
Ellipsis: … (one character). Accented capitals written as such (È, not E').
Numbers: formatted by code (1.234, 3,5 m); percent "{n}%". Puzzle numbers keep "#" ("Sfida del giorno #{n}"); other
numbering is "n. {n}"; ranks "{n}°".
